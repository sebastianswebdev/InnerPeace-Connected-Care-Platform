# InnerPeace Connected Care Platform

A high-fidelity concept prototype showing one connected experience for InnerPeace staff, management, clients and authorised family members.

This repository contains a presentation prototype only. It uses fictional local data and does not provide production authentication, clinical records, or live care-management functionality.

## Prototype experiences

- Staff App — training, progress, resources, policies, announcements, forms and support
- Management Platform — staff onboarding, compliance, reporting, documents, permissions and family accounts
- Client & Family Portal — authorised updates, selected resources, announcements and contact
